# Writing Module

## Context
Use track pad of the laptop or touch screen to draw shapes that matches the task to win the game.

There will be enemies walking from top of the screen toward the bottom of the screen. Each holding cards that contains shapes as the "task". Player has to draw the shapes before the enemies reaches the bottom of the screen.

If shapes were matched the enemies were defeated. If not, they keep going.

The user is able to freely set the total game time. The goal of the player is to keep the enemies from bottom of the screen in the game time.

There will be Beginner, Intermediate, and Hard mode.

### Beginner
- slowest enemy moving speed
- easiest shapes, such as: circle, triangle, square, vertical line, horizontal line

### Intermediate
- faster enemy moving speed
- medium shapes, such as: heart, stars, oval, hexagon

### Hard
- fastest enemy moving speed
- hardest shapes, such as chinese characters: 天、古、元、右、左、夫、吉

## Hardware requirements
- laptop with usable track pad or tablet with touch screen
